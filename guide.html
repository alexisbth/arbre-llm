Ramifai dans Claude

Ramifai garde vos conversations avec Claude sous forme d'arbre (carte mentale). Ce guide explique comment l'ajouter à Claude, sans aucune connaissance technique. Comptez 5 minutes. Vous n'avez besoin ni de GitHub, ni d'installer quoi que ce soit.

Ce qu'il vous faut

  • Un compte Claude (le site claude.ai ou l'application). Selon votre abonnement, Claude peut limiter l'ajout de connecteurs : si l'option manque, regardez l'aide de Claude (support.claude.com).
  • Une adresse e-mail que vous consultez facilement : Ramifai vous y envoie un code pour vous connecter.

Ajouter Ramifai à Claude

  1. Ouvrez Claude sur claude.ai dans votre navigateur (ordinateur ou téléphone), et connectez-vous.

    Une fois ajouté sur le site, Ramifai apparaît aussi dans l'application Claude de votre téléphone.

  2. Allez dans Paramètres (votre nom ou votre photo, en bas à gauche), puis Connecteurs, puis Ajouter un connecteur personnalisé.
  3. Dans Nom, écrivez Ramifai. Dans Adresse (URL), collez l'adresse ci-dessous (touchez-la une fois pour la sélectionner en entier, puis copiez) : https://rhxlsyymnenlvureuxdf.supabase.co/functions/v1/mcp Validez avec Ajouter.
  4. Cliquez sur Connecter à côté de Ramifai. Une page Ramifai s'ouvre : saisissez votre adresse e-mail.
  5. Ouvrez votre boîte mail. Vous recevez un message « Your Ramifai sign-in code » avec un code à 6 chiffres. Recopiez-le dans la page Ramifai.

    Rien dans les 2 minutes ? Regardez les spams / courriers indésirables. L'expéditeur est no-reply@virtom.life.

  6. La page vous montre quel assistant demande l'accès. Cliquez sur Autoriser. Vous revenez dans Claude : c'est fini.

S'en servir

  1. Dans une nouvelle conversation, écrivez : démarrer Ramifai. Pour donner un nom à votre arbre : démarrer Ramifai, arbre « Vacances ».
  2. Claude dessine l'arbre. Ensuite, discutez comme d'habitude : chaque échange est ajouté à l'arbre et l'image se met à jour toute seule.
  3. Pour poser la prochaine question à un endroit précis de l'arbre, touchez une case. Elle devient jaune : votre prochaine question ira juste en dessous.
  4. Plus tard, dites démarrer Ramifai avec le même nom d'arbre pour le rouvrir et continuer.

Questions fréquentes

Les autres personnes voient-elles mes arbres ?

Non. Chaque personne se connecte avec son adresse e-mail et n'accède qu'à ses propres arbres.

Mes arbres sont-ils secrets ?

Ils sont protégés par votre compte et stockés en Europe, mais ils ne sont pas chiffrés de bout en bout : pour répondre, Claude doit pouvoir les lire. N'y mettez pas de secrets très sensibles.

Je ne vois pas « Ajouter un connecteur personnalisé »

Cette option dépend de votre abonnement Claude. Consultez support.claude.com et cherchez « connecteurs personnalisés ».

Le dessin n'apparaît pas

Redites démarrer Ramifai dans une nouvelle conversation. Sur ordinateur, le dessin s'ouvre à droite de la conversation ; sur téléphone, touchez « Ouvrir l'arbre ».

Le code ne marche pas ou ne vient pas

Redemandez-en un depuis la page Ramifai (une seule demande par minute). Vérifiez l'orthographe de l'adresse e-mail et les spams.

Comment enlever Ramifai ?

Claude → Paramètres → Connecteurs → Ramifai → Supprimer.

Les curieux peuvent lire le code, public : github.com/alexisbth/arbre-llm.

Ramifai in Claude — step by step

Ramifai keeps your conversations with Claude as a tree (mind map). This guide needs no technical knowledge and about 5 minutes. No GitHub account, nothing to install.

What you need

  • A Claude account (claude.ai or the app). Depending on your plan, Claude may limit custom connectors: if the option is missing, check Claude's help (support.claude.com).
  • An email address you can read easily: Ramifai sends you a sign-in code.

Add Ramifai to Claude

  1. Open Claude at claude.ai in your browser (computer or phone) and sign in.

    Once added on the website, Ramifai also shows up in the Claude phone app.

  2. Go to Settings (your name or photo, bottom left), then Connectors, then Add custom connector.
  3. As Name, type Ramifai. As URL, paste the address below (tap it once to select it all, then copy): https://rhxlsyymnenlvureuxdf.supabase.co/functions/v1/mcp Confirm with Add.
  4. Click Connect next to Ramifai. A Ramifai page opens: enter your email address.
  5. Open your mailbox. You get a message "Your Ramifai sign-in code" with a 6-digit code. Type it into the Ramifai page.

    Nothing after 2 minutes? Check your spam folder. The sender is no-reply@virtom.life.

  6. The page shows which assistant asks for access. Click Allow. You are back in Claude: done.

Using it

  1. In a new conversation, write start Ramifai. To name your tree: start Ramifai, tree "Holidays".
  2. Claude draws the tree. Then chat as usual: every exchange is added to the tree and the picture updates by itself.
  3. To ask the next question at a precise place, tap a box. It turns yellow: your next question goes right under it.
  4. Later, say start Ramifai with the same tree name to reopen it and carry on.

FAQ

Can other people see my trees?

No. Each person signs in with their own email and only reaches their own trees.

Are my trees secret?

They are protected by your account and stored in Europe, but they are not end-to-end encrypted: Claude must be able to read them to answer. Do not store highly sensitive secrets.

I can't find "Add custom connector"

It depends on your Claude plan. See support.claude.com and search "custom connectors".

The drawing does not appear

Say start Ramifai again in a new conversation. On a computer the drawing opens beside the chat; on a phone, tap "Open the tree".

The code does not come or does not work

Ask for a new one from the Ramifai page (one request per minute). Check the email spelling and your spam folder.

How do I remove Ramifai?

Claude → Settings → Connectors → Ramifai → Remove.

The curious can read the public code: github.com/alexisbth/arbre-llm.
